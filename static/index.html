      Integrate Template from Content Dev or a demo

      Pick where the VM sits now, then enter its exact name. The folder and the VM name are both case sensitive — CAI returns Error if either is off. Show help explains the whole flow.

      A template is built from one VM that already sits in a datacenter, so the source folder and the VM name have to match exactly — CAI folder names are case sensitive, and a wrong case comes back as Error. This form builds the folder for you.

      1. Content Dev: transfer the VM out of the vPod first (section below). It lands in CDEV.RTP/vPod-## and can only be templated in that same DC.
      2. Other DCs: wait for the VM to show up in dCloud, add it to a blank demo, save that demo, then transfer the demo to the other sites like any other content.
      3. CAMGR emails the folder for that transfer — the uppercase site you sent from plus the new demo ID, such as RTP/1348363. Come back with that folder and check every site.
