How to configure Chrome

Do this once in Chrome. WebRDP still opens without it. The browser tab then keeps the name from the VM.

  1. Open a new Chrome tab and go to chrome://extensions. Chrome does not allow this page to open that address for you.
  2. Turn on Developer mode. The switch is at the top right of that page.
  3. Click Load unpacked.
  4. Select the webrdp-tab-title folder. It is inside chrome-extension, in the same folder as this app. That folder contains manifest.json. chrome-extension/webrdp-tab-title
  5. Chrome lists dCloud Content Manager tab titles.
  6. Return to dCloud Content Manager and refresh the page.
  7. Open a WebRDP button. The new browser tab uses the title from Settings.

After an app update, leave the helper loaded. If a tab stops using the title from Settings, open chrome://extensions and click Reload on dCloud Content Manager tab titles, then refresh this app.
