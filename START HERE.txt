dCloud Content Manager (Mac)

Kick the tires: unzip, double-click start.command, log in with YOUR dCloud account.


You need
- A Mac
- Google Chrome
- Cisco VPN or the office network (to reach dCloud)
- Python 3.9+ only if this folder has no runtime directory
  (the -update zip). Install from https://www.python.org/downloads/macos/
  The -full zip already includes Python for Apple Silicon and Intel — skip this.


Start
1. Unzip this folder anywhere (Downloads is fine).
2. Double-click  start.command
   First time macOS may block it:  Control-click start.command → Open → Open
3. First run creates a private .venv in this folder and installs packages there.
   That is only for this tool — it does not install Python for your Mac.
   Chrome then opens to  http://127.0.0.1:8768
4. In the tool, click  Log in to dCloud  and sign in with YOUR Cisco / dCloud account.
   Sessions and saves run as you — not a shared login.
5. Leave the Terminal window open while you use the tool. Close it when you are done.

The version is at the top right of the page (Version 1.0, 1.1, …).
What’s new lists each version in the app and in CHANGELOG.md (also on GitHub).
If this folder is a git clone of the private GitHub repo, or github-update.txt
points at that repo, start.command checks GitHub each launch and only copies a
newer VERSION. Your jobs, logins, .venv, and the bundled runtime/ Python stay
put. Set DCLOUD_SKIP_UPDATE=1 to skip the check.


GitHub (optional, stops the zip shuffle)
The updater is already pointed at the public jasmurra/dcloud-content-manager repo.
Zip installs download public updates directly — no GitHub login, SSH key, Git,
or Xcode Command Line Tools are required. Use Check for updates at the top of
the page, or just start.command; both install a newer VERSION automatically.


Already have the tool? (keep jobs)
Close the Terminal window that is running the tool first.

Unzip the -update zip, then copy the files from the new “dCloud Content Manager”
folder on top of your existing folder. When macOS asks, replace the files.

That is safe. The zip does not contain your jobs, saved-content list, or
logins — those stay in the folder you already have:

  last-job.json
  managed-saved-ids.json
  last-saved-ids.json
  .dcloud-session.json
  .dcloud-cai-session.json
  .dcloud-camgr-session.json
  .env
  .venv

Do not start from a brand-new empty folder unless you copy those files in
first, or in-flight jobs and the saved-content list will not come with you.

Then double-click start.command. Confirm Version in the top right.


If something fails
- “Python 3.9+ is required”
    You have the -update zip. Install Python from the link above, then run
    start.command again — or use the -full zip that already includes Python.
- Login popup blocked
    Allow popups for this page, or click Log in to dCloud and finish Cisco SSO in the tool browser.
- CAI / CAMGR (transfers, integrations, VM replace)
    Click Connect to CAI / Connect to CAMGR. A tool browser window opens for Cisco SSO if needed.


Do not
- Do not send your .env, .venv, or .dcloud-*.json files to anyone.
- This zip is Mac-only.
